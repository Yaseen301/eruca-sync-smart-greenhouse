## Scope

All 94 files from the pinned source revision are included. The upstream root README is preserved as [README-UPSTREAM.md](README-UPSTREAM.md), so the existing research overview remains the main README. Original relative paths are retained for the other source files, including archival documents and fabrication backups.

The import includes PlatformIO firmware source and configuration, compiled firmware binaries, editable STEP models, KiCad projects and footprints, fabrication outputs, bills of materials, build photos, and documentation.

Existing portfolio, poster, and extracted prototype illustrations are retained. Their authorship remains with the team credited in those documents; importing an MIT-licensed implementation does not by itself relicense those separate research materials.
